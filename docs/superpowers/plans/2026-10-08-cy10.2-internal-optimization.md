# cy10.2 — Optimasi INTERNAL UI glitch + fix posisi centang

Tanggal: 2026-10-08 · Cabang: `ui/floating-nav`

## Mandat

Optimasi internal CARA glitch dipanggil/dijalankan. Hasil visual HARUS
identik: tampilan, durasi, intensitas, timing, urutan, target efek, dan
perilaku fitur tidak boleh berubah. Temuan yang berisiko mengubah visual
TIDAK diubah — dicatat sebagai "perlu konfirmasi".

Sertifikat kepatuhan: setiap perubahan yang masuk didukung pembacaan
source framework AOSP (android-14.0.0_r1 / android-15.0.0_r1 /
android-16.0.0_r1) atau penalaran piksel-identik yang eksplisit.

### 1.3 Efek aktif maksimum bersamaan (per skenario)

- Buka dialog aplikasi: 1 window-anim + 1 scanline + N-baris stagger + 1
  glitchTree (N = baris TERLIHAT, ±8–10) → puncak ±12 rantai langkah.
- Pindah halaman cepat berulang: generation counter membatalkan rantai
  lama (finishFrag + removeCallbacks) → puncak tetap ±1 transisi aktif.
- Mengetik cepat: per-keystroke span (clearInputSpans deterministik
  sebelum span baru — tidak menumpuk) + throttle watcher 300ms/node.
- Scroll list aplikasi: bind row = registerTree(dedup)+installTouch
  (listener idempotent); efek hanya pada anak TERATTACH (visible).

### 1.4 Pemanggilan ganda untuk satu event

- `glitchNow + glitchJitter` berpasangan di banyak call site → **dua
  lapis visual berbeda** (span vs displacement), bukan duplikat.
- Checkbox tap → efek press (DOWN) + efek checked (UP) → dua momen
  berbeda, desain cy8 (efek "bertumpuk" disengaja).
- Dialog buka → window-anim (level window) + glitchTree/materialize
  (level konten) → dua lapis berbeda.
- Tidak ditemukan listener ganda/menumpuk pada view yang sama
  (installTouch idempotent; setOnCheckedChangeListener di-null-kan dulu
  sebelum setChecked saat bind).

### Verifikasi non-blokir (dilakukan, tanpa perubahan)

- `installTouch` tidak pernah memasang listener pada EditText (cabang
  Spinner/ViewGroup/Button saja) — keyboard fix cy10.1 tetap utuh.
- Scanline = ViewOverlay (menggambar saja, tidak menyerap sentuhan).
- Korupsi ketik = `Editable.setSpan` (fokus/cursor/selection/IME aman).
- Efek transform = alpha/translationX/scaleX/shadow — TIDAK memicu
  requestLayout; satu-satunya relayout = setText span pada TextView
  yang bersangkutan (inheren visual korupsi teks).
- Semua map efek: WeakHashMap/WeakReference + purge per tick + restore
  terjadwal ≤190ms + `stop()`/`purgeEffects()` membersihkan total —
  tidak ada leak jangka panjang, tidak ada referensi basi permanen.
- R8 + shrinkResources sudah aktif di release (tidak diubah).
- Tidak ada `setLayerType`/`saveLayer` di jalur efek; alpha view
  digambar via RenderNode (efisien).
- `spinnerPulse` (cy6) sudah tidak ada — tidak ada kode mati baru.

### Dua optimasi yang DIBATALKAN saat review mandiri (sebelum build final)

1. Filter `isShown()` pada POOL ambient TICK → mengubah statistik pick
   (pool berisi TextView semua halaman; sebagian pick jatuh di view
   tersembunyi dan memang tak menggambar) → frekuensi ambient yang
   TERLIHAT akan naik. Dibatalkan; hemat CPU dipindah ke guard `burst()`
   (baris #2 tabel atas) yang bebas dari efek statistik ini.
2. Memindahkan `scheduleRestore` TICK ke dalam cabang burst → mengubah
   pola pemotongan umur span saat restore tick beririsan dengan event
   (timing flash berubah). Dibatalkan; komentar penjelas ditinggalkan
   di kode agar sesi berikutnya tidak mengulang kesalahan yang sama.

## 4. BUKTI HASIL IDENTIK (per skenario, sebelum vs sesudah)

| Skenario | Jumlah panggilan glitch | Efek aktif maks | Alokasi | Layout/invalidate |
|---|---|---|---|---|
| Ketik/hapus/paste di search | identik (per-char, jalur sama) | identik | identik | identik (hanya TextView tersebut) |
| Dropdown buka/terbuka/tutup/saat terbuka | identik (foreground) | identik | scanline: −2 objek/panggilan | identik |
| Dropdown terbuka + app ke background | pulse berlanjut → **berhenti** (tak terlihat; resume saat kembali) | 0 di background | −pulse posts | — |
| Dialog aplikasi buka/tutup berulang | identik | identik | scanline: −2 objek/panggilan | identik |
| Checkbox/tombol/navbar/config/split tunnel/mode IP | identik | identik | identik | identik |
| Pindah halaman cepat berulang | identik (generation counter) | identik | scanline: −2 objek | identik |
| Monitor 2 dtk di Dashboard | identik | identik | identik | identik |
| Monitor 2 dtk di halaman LAIN | burst tersembunyi penuh → early-return (0 piksel → 0 piksel) | 0→0 | −span/shadow/restore churn | −(relayout TextView tersembunyi) |
| VPN start/stop/reconnect | identik | identik | identik | identik |

**Fitur yang dipastikan tetap benar**: keyboard muncul di search field
(fix cy10.1 tidak tersentuh), mode Auto/Selalu aktif/Mati bekerja
(isGlitchEnabled dibaca saat event — tidak di-cache), logView bebas
glitch (dikecualikan di registry/collect/burst-guard), tidak ada
artifact kotak (guard elevation tidak diubah), tidak ada state
alpha/transform/shadow/overlay tertinggal (step/cancelFor/stop utuh).

**Checkbox (perbaikan yang diminta)**: box +2dp ke kanan dari tepi
dialog, teks TIDAK menjauh dari box (gap 16dp tetap), tidak ada shift
teks saat toggle checked↔unchecked (kedua state kini struktur
layer-list 20dp eksplisit + offset identik), konsisten untuk semua
dialog bertema (satu-satunya dialog ber-checkbox = Pilih aplikasi;
sumber tunggal = style tema dialog).
